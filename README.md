Isolated virtual lab built with virtualBox and Kali linux for cybersecurity testing and penetration testing practice
Overview:
This project involves building an isolated cybersecurity testing environment with VirtualBox and kali linux. The lab is designed to support practical security exercises, including reconnaisance, network scanning, vulnerability analysis, and penetration testing, in a safe and repeatable manner. A private virtual network is used to facilitate the future integration of additional virtual machines, which can serve as targets for authorised security assessments.

OBJECTIVES;
install and configure VirtualBox
install\import Kali Linux as a virtual machine.
create a private NAT Network for the cybersecurity lab
configure network connectivity for kali linux
assign an IP address to the kali VM 
Verify network connectivity and DNS resolution
take a clean VM snapshot for recovery
Document the complete setup process 
prepare the environment for future cybersecurity projects
